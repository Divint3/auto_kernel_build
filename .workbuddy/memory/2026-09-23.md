- 用户提出 allnoconfig 快速编译方案，评估发现关键坑：allnoconfig 会关掉所有 default y 选项
  - TTY=n → PL011 串口被 olddefconfig 静默丢弃；BLK_DEV_INITRD/RD_GZIP/BINFMT_ELF 缺失 → initramfs 引导 panic；MODULES=n → 模块功能丢失
  - CONFIG_CMDLINE_BOOL 是 x86/mips 选项，arm64 无此符号（直接用 CONFIG_CMDLINE，QEMU -append 会覆盖）
  - 修正方案已合入 workflow：新增 minimal_config 开关（默认 true），allnoconfig + 补齐必需符号 + olddefconfig 后回读 .config 校验（防静默丢弃）+ modules_prepare
- 经验：kconfig minimal config 通用流程 = allnoconfig → scripts/config 补项 → olddefconfig → grep 回读校验关键符号
